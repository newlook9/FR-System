# FR System — حصہ 1 (ریکارڈ سسٹم)

## چلانے کا طریقہ
1. Python 3.9 یا نیا انسٹال ہو (کوئی اور چیز انسٹال کرنے کی ضرورت نہیں)
2. Windows: `run.bat` پر ڈبل کلک — Linux/Mac: `./run.sh`
3. پہلی بار ٹرمنل میں admin کا پاس ورڈ لکھا آئے گا (اور `data/INITIAL_ADMIN_PASSWORD.txt` میں بھی)
4. براؤزر میں `http://localhost:8000` کھولیں۔ دوسرے کمپیوٹر/موبائل سے: `http://<اس PC کا IP>:8000`
5. پہلے لاگ اِن پر پاس ورڈ بدلنا لازمی ہے

## اس حصے میں کیا ہے
ریکارڈ (شخص + مقدمات)، تلاش، کردار (admin/officer/viewer)، آڈٹ لاگ، اردو/انگلش (جمیل نوری نستعلیق)، لوگو۔

## ابھی باقی
- حصہ 1ب: Android APK + GitHub Actions (unzip اور APK بنانا)
- حصہ 2: چہرہ پہچاننے کی سروس — حصہ 3: الرٹ اور تھانہ روٹنگ — حصہ 4: سیکیورٹی، HTTPS، Docker

`data/` فولڈر میں ڈیٹا بیس اور تصاویر ہیں۔ اپڈیٹ پر اسے نہ مٹائیں۔
