# FR System — حصہ 1 (ریکارڈ سسٹم)

## چلانے کا طریقہ
1. Python 3.9 یا نیا انسٹال ہو (کوئی اور چیز انسٹال کرنے کی ضرورت نہیں)
2. Windows: `run.bat` پر ڈبل کلک — Linux/Mac: `./run.sh`
3. پہلی بار ٹرمنل میں admin کا پاس ورڈ لکھا آئے گا (اور `data/INITIAL_ADMIN_PASSWORD.txt` میں بھی)
4. براؤزر میں `http://localhost:8000` کھولیں۔ دوسرے کمپیوٹر/موبائل سے: `http://<اس PC کا IP>:8000`
5. پہلے لاگ اِن پر پاس ورڈ بدلنا لازمی ہے

## اس حصے میں کیا ہے
ریکارڈ (شخص + مقدمات)، تلاش، کردار (admin/officer/viewer)، آڈٹ لاگ، اردو/انگلش (جمیل نوری نستعلیق)، لوگو۔

## حصہ 2: چہرہ پہچاننا
1. ایک بار انٹرنیٹ کے ساتھ: `pip install -r requirements-face.txt` (Python 3.9 تا 3.11 بہتر ہے)۔ پہلی بار چلانے پر ماڈل (تقریباً 300MB) خود ڈاؤن لوڈ ہوگا
2. سرور دوبارہ چلائیں۔ اب ریکارڈ میں تصویر محفوظ کرتے ہی چہرے کا ڈیٹا بن جائے گا، اور "چہرے سے تلاش" کھل جائے گی
3. پرانی تصاویر کے لیے: سیٹنگز ← "تمام محفوظ تصاویر سے چہرے کا ڈیٹا بنائیں" (صرف admin)
4. کیمرے: `cameras.example.json` کو `cameras.json` نام سے نقل کریں اور اپنے کیمروں کے RTSP پتے لکھیں، پھر `python recognizer.py` چلائیں
5. صرف حیثیت "مطلوب" یا "مفرور" والے لوگ کیمرے کی واچ لسٹ میں جاتے ہیں۔ شناخت "شناخت الرٹس" صفحے پر آتی ہے، جہاں افسر "درست/غلط" لکھتا ہے
6. غلط الرٹ کم کرنے کے لیے `FRS_THRESHOLD` بڑھائیں (ابتدائی 0.55)۔ `cameras.json` میں پاس ورڈ ہوتے ہیں، اسے کبھی GitHub پر نہ ڈالیں

## ابھی باقی
- حصہ 1ب (شامل): Android ایپ، APK بنانے کا ورک فلو
- حصہ 3: الرٹ اور تھانہ روٹنگ (کیمرہ ← علاقہ ← تھانہ، Telegram) — حصہ 4: سیکیورٹی، HTTPS، Docker

`data/` فولڈر میں ڈیٹا بیس اور تصاویر ہیں۔ اپڈیٹ پر اسے نہ مٹائیں۔

## APK
زپ کے ساتھ ورک فلو (`fr-system.yml`) APK بناتا ہے۔ ریپو کے **Releases ← latest-apk** سے `FR-System.apk` فون میں ڈاؤن لوڈ اور انسٹال کریں۔
پہلی بار ایپ سرور کا پتہ پوچھے گی، مثلاً `192.168.1.10:8000` (سرور والے PC کا IP)۔ فون اور PC ایک ہی نیٹ ورک پر ہوں۔
